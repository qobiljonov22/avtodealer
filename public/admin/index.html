WordPress Admin

Sayt matnlari WordPress orqali boshqariladi. Admin ochilishi uchun PHP + MySQL kerak.

Local (ishlaydi)

OpenServer yoqilgan bo‘lsin → oching:

http://avtodealer.local/wp-admin

Avtodealer Studio: chap menyu → Avtodealer

Vercel (bu domen)

Bu yerda faqat statik preview. PHP yo‘q → /wp-admin ochilmaydi.

Vercel xavfsizlik qoidasi /wp-admin ni 403 Forbidden qilib bloklaydi — bu tema xatosi emas.

Serverda ham admin kerak bo‘lsa

  1. Desktopdagi avtodealer-FULL-WordPress-PHP.zip ni oching
  2. Beget / Hostinger / Timeweb (PHP + MySQL) ga wordpress/ ni yuklang
  3. O‘rnatishdan keyin: https://SIZNING-DOMEN/wp-admin
  4. wp-config.php ichida That's all, stop editing! dan oldin:
    require_once __DIR__ . '/wp-content/themes/avtodealer/hosting-wp-config.php';

Shu PHP domen — asosiy sayt + admin. Vercel faqat ko‘rib chiqish uchun qolishi mumkin.
